# povo vault

povo のコードを端末内で管理する、単一ファイルのWebアプリです。

## 使い方

https://ocra855.github.io/povocodekanri/
をブラウザーで開き、コードを登録します。期限、使用状況、購入金額を管理でき、検索・バックアップにも対応しています。

使用期間の終了日時は、使用開始日時から「日数 × 24時間」で計算します。例：7日間は168時間です。

## 通知

使用開始日時と使用可能期間を設定し、コード詳細から「カレンダーに登録」を選びます。通知タイミングの既定値は設定画面で選択できます。通知時刻はコードの使用期限時刻が初期値です。「.icsを作成」でファイルを作り、カレンダーに読み込んでください。

## データ

コードや設定はブラウザーの IndexedDB に保存され、外部には送信されません。ブラウザーのデータ消去やプライベートブラウズではデータが失われることがあります。設定画面から定期的にバックアップを書き出してください。
